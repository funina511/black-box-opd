## 4. 方法定义

### 4.1 Critic 学习目标保持不变

```text
L_critic = L_BT + λ × L_aux

L_aux = (1 / 3) × Σ_d [min(N_d / τ, 1) × L_d]
```

沿用现有 `fixed_dimension_gated` 实现：`λ=0.1`、`τ=4`，`L_d` 是该维有效标签上的加权平均 BCE，`N_d` 是现有去重与全局计数口径下的有效权重总量；没有有效标签的维度贡献为零。

继续保留 Teacher / Student 去重、DP 与梯度累积归一化。0.5 仍是软标签。错误严重度头继续学习“越大表示错误越严重”，不翻转训练标签。

### 4.2 Actor 奖励

设最后一个有效回答 token 上的四头 logits 为 `z_adv, z_c, z_p, z_e`，定义：

```text
c = sigmoid(float32(z_c))
p = sigmoid(float32(z_p))
e = sigmoid(float32(z_e))

r_rubric = w_c × c + w_p × p − w_e × e
r_actor  = z_adv + β × r_rubric
```

约定：

1. 对抗评分 `z_adv` 保留原始定义；三个 rubric 头映射到 0～1 后混合。
2. 正确性、进展为正向项，错误严重度为负向项。没有错误不代表已经解决题目。
3. `β` 是 Actor 奖励系数，与 Critic 辅助损失系数 `λ` 独立。
4. 首轮三个维度权重固定为 `1, 1, 1`，不自动重新归一化权重；此时 `r_rubric` 的取值范围为 `[-1, 2]`。首轮只选择一个整体 `β`，避免同时搜索多个维度权重。
5. 分数是 Critic 的预测，尤其进展与错误维的 sigmoid 值不是经过独立校准的“正确概率”。
6. 奖励计算沿用 `no_grad`，不把 BCE 加到 Actor loss，也不通过 Actor 更新反向训练 Critic。

混合仍是回答级奖励：只放在最后一个有效 token 上，padding 位置为零。长度截断时使用最后一个有效回答 token，不强制要求 EOS。当前整条可见回答标签不能直接充当每个中间 token 的标签。

### 4.3 标签抽样与预测奖励分开

Judge 继续使用 `direct_v1` 单轮 Thinking，每个全局逻辑 Critic minibatch 最多选择 16 条唯一轨迹，replay 关闭。正确性继续由现有统一数学评分器产生标签。

Actor 对本轮所有学生 rollout 使用 Critic 的预测，包括本轮没有被 Judge 抽中的回答。Judge 是否标注的 mask 只用于辅助损失，不能拿来把未标注回答的 Actor 奖励清零。

`null` 也不能转换成“没有错误”或“没有进展”的真实标签。此次不新增置信度模型、额外复核或标签数量门控。Judge 调用预算保持不变，四头分数复用现有 Critic 前向。

### 4.4 更新顺序保持不变

```text
Student rollout
  → 当前 Critic 前向，得到四头分数和混合奖励
  → 按原 GRPO 计算优势
  → 沿用当前在线标注与 BT + rubric 更新 Critic
  → 按既有 GRPO / KL 设置更新 Actor
```

奖励来自本步 Critic 更新之前的模型。不要为了获得“最新分数”再对同批回答做第二次前向，也不要更换 GRPO 或调整原 KL 系数。

## 5. 最小配置与代码修改

### 5.1 配置

建议新增以下字段；名称可按现有风格作小调整，但必须把训练损失系数和奖励系数分开：

```yaml
rubric:
  reward_source: adv_plus_rubric  # 保留 adv_only，作为默认及对照
  actor_reward_coef: 0.1         # 仅为固定样本诊断候选，不是已确认的正式值
  actor_reward_weights:
    answer_correctness: 1.0
    verified_progress: 1.0
    unresolved_error_severity: 1.0  # 非负权重；负号在奖励公式中统一处理
```

兼容默认值为 `reward_source=adv_only`、`actor_reward_coef=0`。只做必要校验：模式受支持、数值有限且非负、启用混合时维度布局正确；正系数混合模式至少有一个正权重。首版混合模式限定为本轮的 `math_process_v2 + joint + direct_v1`。

GAD worker 接收所选奖励配置；Warmup 的有效模式保持 `adv_only`。SeqKD 无此扩展。旧配置缺少新增字段时继续走原路径，不要求重新编辑历史实验配置。

**不要把 Actor 权重写入 rubric spec/prompt。** 来源 Critic 已绑定现有 `rubric_hash`；这次只改变分数的使用方式，标签语义与 spec 内容应保持一致。

选定一个 `β` 后冻结到完整启动配置，并记录选择依据。若三个头明显没有区分力，应报告结果，而不是不断放大系数来制造翻转。

## 8. 日志应回答什么

当前正式配置是 `rollout.n=2`、GRPO 组内标准差归一化开启。非平局且分差远大于数值容差时，两条回答的优势近似只由排序决定；混合奖励数值上升不等于 Actor 获得新信号。

最少记录：

| 指标 | 用途 |
| --- | --- |
| adv、c、p、e、rubric 贡献和总奖励的均值/标准差 | 判断量级、饱和或信号消失 |
| 同题排序翻转比例、原始/混合平局比例 | 判断 rubric 是否实际改变相对偏好 |
| 非零优势组比例，必要的优势差异摘要 | 验证信号确实进入 GRPO |
| 现有数学正确率、长度、截断比例 | 防止只看到模型自己的奖励上涨 |
| 原有 BT / 辅助损失和 KL 指标 | 观察 Critic、Actor 是否稳定 |

排序按 driver 端完整 batch 的题目 uid 分组，不能在 microbatch 或单卡上随意配对。显式分开平局与严格翻转，报告统计分母。正确率只使用现有评分结果；scorer unknown 不强行当作已知错误。

这些指标接入当前日志和 W&B，不新增另一套监控系统。奖励增长不能替代独立评测结果。

### A.2 截断回答的奖励偏向（对应 4.2 节；先测量，暂不定处理方案）

标签规范规定“未完成不是过程错误”。历史样本中，W 的严重错误标签比例高于 T；这是一个需要检查的潜在激励差异，但不能仅凭未完成就断言 T 应比 W 差。按标签计算的结果如下：

| 类别 | p/e 均有效条数 | 三项均有效条数 | y_p=1 比例 | y_e=1 比例 | 平均 y_c+y_p−y_e |
| --- | ---: | ---: | ---: | ---: | ---: |
| C | 389 | 389 | 92.8% | 4.4% | +1.886 |
| W | 842 | 842 | 8.0% | 89.1% | −0.418 |
| T | 1584 | 1573 | 18.4% | 35.0% | +0.087 |

过程标签比例使用“p/e 均有效”分母；最后一列只使用“三项均有效”样本。另外 4 条 p/e 有效的 U 未列入三类均值。全部 34,432 条学生回答中有 128 条正确性 unknown，其中 107 条为 T、21 条为 U；还有 **49 条 T 的有效正确性标签为 1**，说明长度截断不等于一定答错。

同题组合分布可复现：TT 43.1%、TW 22.6%、WW 14.4%、CW 7.6%、CT 6.6%、CC 5.6%；另有 21 对含 U，应单列而不是归成答错。上表的 T/W 平均差跨越了不同题目，**不能直接替代同题 TW 的奖励差**。在原记录中，仅有 22 对 TW 的两条回答都具备三项有效标签：标签组合分数偏向 T 14 对、偏向 W 4 对、平局 4 对。这支持进一步检查，尚不足以证明新 Actor 会学会拖延或长期偏爱截断。

这种偏好也可能符合过程监督的目的：未完成但推理有效的回答，可以优于写完却明显错误的回答。需要警惕的是奖励是否鼓励空话、重复、不必要拖延，或者以降低可完成率为代价提高模型自评分。历史有效步骤中，首 50 步与末 50 步的平均学生截断率分别为 69.50% 和 54.89%；这一趋势可作为描述性参照，不能据此预先断言混合奖励会破坏它。

本轮要求：

1. 固定样本和训练日志单独报告 TW 的成对预测分差、两方向翻转数、平局数及有效分母；T/W 全局平均分仅作补充。T 中正确、错误与 unknown 的数量也保留。
2. 对少量偏向 T 的翻转查看回答内容，区分“有实质进展的未完成解答”和“重复、空话或错误拖延”。不要把所有偏向 T 的翻转都计为有害。
3. 同步观察真实正确率、完成率/截断率和长度。只出现 T 均值更高或少数翻转，不新增自动阻断或强制惩罚；若成对分析及案例均显示明显不良激励，在实施报告中突出说明，供用户安排正式实验时取舍。
4. 本轮暂不引入截断惩罚，也不取消错误项。后续若考虑处理方案，应作为明确的新方法变化，不能由实施模型偷偷加入首版。

原讨论中的两个候选保留为研究备选，但需要准确解释：

- **截断时奖励端强制 `e=1`**，等价于额外减去 `β × w_e × (1−e) × I[截断]`。这是一个依赖预测值的截断惩罚，会对原本预测错误较少的截断回答扣得更多，不是数学错误标签的纠正；也可能惩罚正确但随后继续生成的回答。若以后采用，必须独立记录该项，而不能混入“错误严重度预测”的校准指标。
- **令 `w_e=0`** 可以检验错误项的作用，但会同时删除正常回答中有用的错误区分。两类历史标签均值变近不证明该方法会改善训练；它属于消融，不是已经确定的修复。

后续若换用新数据，应重新建立相同起点、相同预算的对照，并在对应 Warmup 上测量这些风险。Teacher 数据更短不保证 Student rollout 更短；不能只换本轮数据后继续把旧 naive rubric 作为纯奖励消融对照。

### A.3 进展、错误项与正确性高度重合（对应第 10 节）

在这批有标签样本中，C 与 W 的平均标签组合分差约为 2.30，其中正确性标签贡献 1，进展减错误贡献约 1.30。这说明过程标签与结果正确性有较强关联，值得检验是否只是重复放大正确性信号。

**不能因此把完整奖励等同于“2.3 倍正确性奖励”。** 该数字是跨题、抽样标签上的条件均值差；实际使用的是 Critic 预测值，还要与 adv 混合并进行 GRPO 同题归一化。组内分差、相关误差和排序才决定 Actor 获得的信号。

保留按组合分类的诊断，但不按类别直接认定原因。WW 的两个真实正确性标签虽然都为零，预测 `c` 仍可能不同；TT 也可能含正确答案。反过来，过程头完全可以在 CW 上改变排序。因此“CW/CT=正确性驱动、TT/WW=过程驱动”的旧表述取消。

在同一批四头输出上离线比较以下三种奖励，不增加模型前向：

```text
R_adv  = z_adv
R_c    = z_adv + β × w_c × c
R_full = z_adv + β × (w_c × c + w_p × p − w_e × e)
```

分别报告 `R_adv → R_c` 和 `R_c → R_full` 的排序变化，并列出同题 `Δc、Δp、Δe、Δadv`。第二个比较反映过程头的增量贡献，但仍不能仅凭它断言过程语义正确或正式训练有收益。

正式实验加入“只接入正确率预测”的基础消融：与完整版本保持相同 `β` 和 `w_c`，令 `w_p=w_e=0`，Critic 仍接受相同三维辅助训练。**实施模型负责配置和离线比较，完整消融训练仍由用户安排，不增加本轮 GPU smoke 组数。**

该消融可以检验增加过程头的效果，但不能完全排除整体奖励强度变化。若后续要声称收益来自新增过程信息，而非正确性信号放大，可再用 `z_adv + αc` 在固定开发样本上做有限量级对照，必要时由用户安排正式的强度匹配实验；不把它扩展为本轮额外的必跑矩阵。

### A.4 预测值的在线校准监控（对应第 8 节）

Critic 的输入只有题目和回答，需要学习判断数学内容是否成立，不能保证不会利用是否写完、语气或格式等捷径；但看不到标准答案不等于它只能判断“看起来是否正确”。这是需要监测的风险，不是已经证实的模型行为。

`gad_extensions.prepare` 会为学生回答取得现有正确性标签，并为抽中回答取得过程标签。奖励使用本步 Critic 更新前的预测，可以和这些标签对照，增加统计计算但无需额外推理。该监控衡量预测与标签的一致性，不改变模型输出，不属于在线校准算法或额外训练损失。

建议按 10 步窗口汇总，并同时记录样本数；不足 10 步时输出实际已有步骤的结果并注明窗口大小，使 3 步 smoke 也能核查指标：

| 指标 | 用途 |
| --- | --- |
| 正确性标签有效的学生上，`mean(c)`、`mean(y_c)`、均值偏差和 `mean((c−y_c)^2)` | 观察预测水平与实际标签、均方误差；按是否截断分别统计 |
| 同一集合的 c-AUC（窗口同时含正负例时） | 衡量排序区分能力；只有一类时记为 N/A，不停止训练 |
| 本轮被抽中且对应标签有效的学生上，p/e 各自的均值偏差和 MAE | 使用相同有效样本逐项比较；支持 0、0.5、1 软标签，不使用含糊的浮点“完全一致率” |
| 分组合的 `R_adv → R_c`、`R_c → R_full` 及总翻转和平局数量 | 区分分量作用，保留 TW 的翻转方向 |

AUC 或按 0.5 阈值的准确率衡量的是区分能力，不能单独称为概率校准。过程头与 Judge 一致也不等于数学上独立验证正确；保留有限案例抽查，不因这些指标再增加 Judge 请求。

实现约束：

- 复用正文 `[batch, 4]` 分量，明确它们来自本步更新前的模型。数学 scorer 的 `valid=false` 不参与误差/AUC，计入 unknown；现有 `no_answer → 有效标签0` 的映射保留，不能只看原始 `correct=null` 就当作无效。
- 不将缓存 `values` 字典的顺序直接视为 Actor 行顺序。优先使用 `prepare` 返回的学生 target/mask 张量与明确的样本身份对应；本轮 replay 关闭时行序沿用 fresh batch，但测试需覆盖重复回答、去重标签展开和 DP 拼接。无需为此重构 runtime。
- 过程统计使用本轮有效 mask：缓存存在但本步未选中的标签不纳入过程监控。Teacher 标签不能混入学生指标。
- 保存恢复时复用现有日志，按已提交 step 去重汇总窗口；无需额外持久化一套监控状态。

可选的“GAD + 数学评分器正确性”参考组仍由用户决定。它能比较 learned reward 与工具结果奖励，不是过程信号增益的充分因果证据。

### A.5 固定样本检查的调整（对应第 7 节）

**先检查是否已有可复用的成对开发样本，再生成缺少的数据。** 原标签批次可还原类别统计，但不含完整回答；有限 calibration 文本和单回答贪心验证不能直接替代训练设置下的同题双回答。不要据此扩大成重新采集全部训练数据。

样本规模与生成设置：

1. 从 `gad_dev` 固定一个打乱顺序，先取 128 题，每题 2 条。若关键组合不足以说明情况，再沿相同顺序补到 256、最多 512 题；不覆盖已生成回答。如果已有完整 512 题且设置一致，直接复用。
2. 使用起点 Warmup 的 Actor、训练模板、non-thinking、temperature=0.8、top_p=1.0、相同其他采样设置和固定种子，输出上限 8192。原 GAD 的类别比例只能估计样本需求，不能保证 Warmup 上也出现相同比例。
3. 复用现有采样能力，在本轮诊断材料中保存题目身份、回答、finish_reason、长度、采样配置和 scorer 身份。接口能提供时保留 token IDs；只有文本重编码时说明限制，不把它当作精确训练轨迹回放。
4. 用统一评分器取得正确性标签，按 A.1 分层。Judge 参考最多 32 条，优先覆盖需要解释的翻转及少量未翻转对照；说明这是定向抽查，不能将其准确率推广到全部回答。无需重新开展 Judge 模型比较。

64 题按历史 CW 比例预计只有约 5 对，确实偏少；但即便扩到 512 题，可用翻转数也可能很小。所有比例同时给出分子、分母；样本少时写明不确定，不为了达到某个百分比继续扩样或增加 rollout 数。

Critic 的检查顺序：

- **必做：step271。** 用同一次四头输出离线比较正文候选 β，以及 A.3 的三种奖励。直接服务于本轮真实起点。
- **可选：step542。** 若资源允许，在同一批回答上用原实验末期 Critic 检查量级是否大幅变化；只有发现值得解释的变化时再考虑 step400。三个 checkpoint 当前均存在，但不要求把三次长序列推理全部变成准入条件。
- step400/542 所属旧实验的 Actor 只使用 adv 奖励，Critic 仍接受 BT + rubric。它们只能提供历史量级参考；固定 Warmup 回答上的打分也不能代替新策略的在线分布。因此新实验中的漂移主要通过 A.4 监控，首版不增加动态 β 调整。

β 的选择原则在运行前固定，但**不把“翻转率10%–25%”或“正确方向至少80%”作为硬阈值**。这些区间没有当前数据上的充分依据，也可能鼓励放大噪声。改为：

1. 排除实现错误、分量接反和数值不稳定；报告信号是否几乎恒定或被 adv 完全淹没。
2. 对有效、确有一对一错的回答对，比较混合前后把正确回答排前面的数量（平局单列或固定计0.5），同时记录纠正排序和破坏排序的数量。CT 必须检查 T 的实际正确性，不能假定所有 T 都错误。
3. TW 的偏向结合有效进展、错误和冗余内容判断，不要求一律偏向 W。
4. 在有可解释作用、且没有明显不良激励的候选中选择较小的非零 β，冻结后进入已有的短训练验证。少量样本不能保证正式效果；没有清楚证据时如实报告，不为了达到目标翻转率扩网格、反复加 Judge 或设置新审批门槛。

若所有候选都没有作用，或出现明确相反方向，报告具体分差和案例，供用户决定正式实验；本轮最多 3 个 GAD 更新的验证预算不因此扩大。若以后更换数据，则在对应 Warmup 上重新做必要检查，并重新确定公平对照，沿用 A.2 的约束。
